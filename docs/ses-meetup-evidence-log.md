# SES営業交流会 Evidence Log

この記録は、SES営業交流会申込サイトおよび周辺運用について、実際にどのように使われたか、どの程度の手動対応が残ったか、どんな例外が発生したか、運営作業にどれくらい時間がかかったかを開催単位で残すためのものです。将来の業務改善評価に使います。

## 記録上の重要事項

- 推測値を書かない。
- 不明な値は「未計測」または「未確認」とする。
- `0件`と`未計測`を区別する。
- 過去開催分を、後から感覚や記憶で埋めない。
- 良かった結果だけでなく、問題、例外、悪化も残す。
- 参加者氏名、メールアドレス、電話番号、個別企業の秘密情報、個人を特定できる問い合わせ本文は記録しない。

## 用語と記録方法

| 用語 | 定義 |
|---|---|
| 手動対応 | システムだけでは完結せず、運営者が個別に内容を確認・修正・連絡したもの |
| 例外 | 通常フローでは処理できず、追加対応が必要だった事象 |
| 未計測 | その回に計測方法がなく、値を確認できない状態 |
| 未確認 | 確認する必要はあるが、記録時点で確認できていない状態 |
| 0件 | 対象の確認を行い、発生しなかった状態 |

時間は実測できる場合に実測する。難しい場合は開始・終了時刻を残して算出する。後から感覚で所要時間を推定しない。

## Evidence Level

| Level | 定義 |
|---:|---|
| 0 | 作成のみ |
| 1 | 自己利用 |
| 2 | 他者試用 |
| 3 | 他者継続利用 |
| 4 | Before / Afterで業務指標変化 |
| 5 | 複数人・複数業務または期間で再現 |

SES営業交流会サイトは現時点でLevel 1とする。公開URLや動作画面だけでLevelを上げない。開催記録を2〜3回分蓄積しても、比較条件と測定方法を説明できるまで「改善した」とは判断しない。

## Before・比較・正規化の扱い

過去開催について確認できる申込数、キャンセル数、開催人数は記録できる。ただし、作業時間、手動修正、問い合わせ数、例外数などの記録が残っていない場合は`未計測`とし、推定で埋めない。

次回開催を最初の正式な測定回とし、最低限、申込数、キャンセル数、手動修正数、問い合わせ数、例外件数、管理時間、開催条件を記録する。1開催だけでは改善を判断しない。まず2〜3開催の実測値を蓄積し、同程度の開催条件で比較する。

実測値が揃った後、開催規模の違いを考慮するため、次の指標を算出できる。

| 指標 | 式 | 計算条件 |
|---|---|---|
| 問い合わせ率 | 問い合わせ数 ÷ 有効申込数 | 分子・分母が確認できる |
| 手動修正率 | 手動修正数 ÷ 有効申込数 | 分子・分母が確認できる |
| 例外率 | 例外数 ÷ 有効申込数 | 分子・分母が確認できる |
| 1申込あたり管理時間 | 申込管理時間 ÷ 有効申込数 | 時間・分母が実測できる |

このテンプレートには架空の実測値を入れていない。値が記録できない場合は、計算しない。
